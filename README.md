# 生成式 AI 与 Agent：从模型训练到系统实践

一本写给**学过机器学习与神经网络、正要进入生成式 AI 的计算机专业本科生**的中文技术书。目标是从语言模型的训练与生成讲起，逐步走到工具调用、运行框架、上下文与缓存，再讨论可靠性、安全、评估、多模态生成及当代模型与 Agent 产品。

[连续阅读完整书稿](书稿/全书.md)。分章文件是编辑底稿；修改分章后，运行 `python3 scripts/build_book.py` 更新连续阅读版。

书中的机制与流程图使用 Mermaid 编写，可在 GitHub 的 Markdown 页面直接查看；图旁也有文字解释，便于纯文本阅读。

## 写作原则

1. 先解释读者会遇到的现象，再解释它背后的机制，最后说明工程上怎样处理。
2. 区分模型、产品、运行框架和外部工具的责任；不把某一家的实现当成所有系统的通则。
3. 贯穿使用“查天气”和“修改文件”两个例子。新增概念要能接回这两条主线。
4. 对重要事实给出可核对的来源；示意数字和伪代码明确标为示意。
5. 按章节扩写，完成一章就检查与前后章节的衔接、术语和重复内容。
